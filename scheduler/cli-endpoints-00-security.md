/goal Führe ein ausführliches security audit durch. Jegliche Sicherheitslücken, Risiken für Datendiebstahl, unsicherer Code, Anfälligkeit für sql injection oder sonstige OWASP Sicherheitslücken oder CVEs. Dokumentiere dann jede Datei, die du durchsucht hast mit Namen in audit.md. Behebe alle Sicherheitslücken, die du ohne Breaking changes beheben kannst und dokumentiere den Rest ebenfalls in audit.md. Dateien, die bereits untersucht wurden, sollen erst nach einer Woche wieder untersucht werden, außer sie haben sich zwischenzeitlich geändert. Nach einer Woche darfst du die Dateien erneut untersuchen, passe dann das Datum an. Das Ziel ist erreicht, wenn das Security Audit abgeschlossen ist und alle offenne Punkte sowie die gecheckten Dateien in der audit.md dokumentiert sind.
