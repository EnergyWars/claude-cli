Wichtig, halte dich genau an folgende Anweisung:
Wenn du eine Anweisung von mir bekommst, code zu schreiben, dann machst du einen git worktree in einem temporären ordner in /tmp auf. Dort machst du deine Änderung und mergest sie dann in diesen Branch hier zurück. Wenn Konflikte auftreten, behebe sie im Sinne deiner Changes und die des anderen.
Wenn alles im Branch zurück ist, lösche deinen Worktree-Branch wieder.
